# AirGesture · 隔空手势 A3
独立 Android 实验应用。首次目标 MatePad Air 2023 / HarmonyOS 4.2 / Android 12，未真机验证。无需 Root、Vector、接近光传感器、软重启；与 GazeReader 不同时占用前置相机。
手掌稳定停留约650ms，出现就绪提示后2.5秒内向上下左右挥动；握拳截屏需独立开启，先张掌就绪再握拳650ms。动作后移开手掌解除冷却。识别仅在本地，手势只派发至明确选择的全屏应用；小窗、分屏、键盘、锁屏暂停或停止。可在软件内测试识别，不执行任何系统动作。
项目为独立源码树，暂以 GazeReader 的 airgesture-a1 分支作为 CI 构建载体，不改动 main 或 U2。正式仓库需另建。
参考 [GestureControl](https://github.com/Git-Frk/GestureControl) 的 Kotlin/CameraX/MediaPipe、确认状态机与无障碍控制设计，固定提交 be9d90553e0e0ec4d6f5d531594e26a6fdd9076c；参考 [Air Gesture Hub](https://github.com/Autumn-oy/Air-Gesture-Hub) 的手掌激活和冷却概念，固定提交 ab634b6e0b622d51ef3b7094c0532b656a44b3de。未复制上述项目业务代码。相机框架由本账号 GazeReader 相机处理逻辑调整。Google MediaPipe 手模型从固定官方模型 URL 下载并校验哈希，附 Apache-2.0。所有设备兼容性、手势识别精度及截屏行为待验证。

## A1R1 文字互动提示
独立识别页大字状态：等待手掌、姿势不符、驻留百分比、就绪、移动进度、握拳确认、超时、冷却；区分识别成功与系统回调。选定应用内非触摸提示支持开关和顶部/底部位置；仅在目标应用活动时显示，截屏请求时短暂隐藏提示，不能保证系统截图完全不含提示。目标窗口不符合条件时显示原因，不放宽手势派发保护。原识别阈值、相机和动作保持不变。CI 调试签名可能不同，无法保证覆盖安装。尚未真机验证。

## A2
删除水平挥动识别，保留上/下挥手（平滑、独立距离阈值、方向竞争），新增手心→手背映射左滑、手背→手心映射右滑；使用手部关键点三维平面法向量的有符号朝向代理，不是掌纹识别。五项各自校准，同一只手、不同屏幕方向分别保存；两种翻掌起始符号必须相反。仅校准成功的手势可触发。握拳截图仍需显式开启。全局模式不要求选择应用，控制活动应用窗口，切换窗口重置识别，安全限制保持（锁屏、系统/敏感包名、输入法、覆盖、太小窗口；敏感包名过滤不是完整安全识别）。桌面及分屏活动窗口支持是实验性的。去除15分钟上限，旋转重建相机、读取方向校准，锁屏/过热/相机错误停止，不后台自动启动。不保证所有场景均可用。A2 未真机验证；不同调试签名可能需卸载旧版。

## A2R1 上挥专项修订
上挥要求校准时手背朝摄像头，记录起始朝向符号（同一只手），允许自然弯指、上挥时朝向变化，采用原始掌心中心位移的两帧判定，不需终点停留。校准上挥至少两帧有效上移，距离阈值取采集峰值50%，限制横向干扰及握拳。旧上挥配置无起始朝向符号，自动失效；其他四项保留，重新安装或不同签名可能丢失数据。朝向符号依赖用户正确示范，不独立验证手背，未真机验证。

## A2R2 翻腕上挥（替代 A2R1 上挥）
起始手背朝镜头、指尖向下；翻腕上挥，终点手心朝镜头、指尖向上。用腕点到四指指尖均值的三维方向、手部平面法向符号反转及指尖实际向上位移联合识别，不要求掌心中心显著上移。终点两帧确认。上挥起始姿势一旦就绪，本次动作独占上挥，不误触普通翻掌/其他动作；普通翻掌请保持指尖向上。上挥独立新配置键，旧上挥校准自动失效，其他四项保留（覆盖安装时）。朝向正负依赖同一只手的正确示范，不是真正的掌纹识别。未真机验证。

## A3 七手势映射
翻腕上挥=上滑，向下挥=下滑，原地手心→背=系统返回，原地手背→心=活动窗口中心点击（全屏即屏幕内容中心），横向手心左挥→背=左滑，横向手背右挥→心=右滑，握拳=截图（显式启用）。横向指尖起始独占横向动作，普通翻掌必须指尖向上且整段位移不超过独立校准上限；错误动作拒绝不降级。横向需要有方向的位移及面向反转，七项独立校准，两种原地翻掌需重校，新增两项横向校准，其他三个配置保留。所有动作仍检查活动窗口及原有安全场景，不绕过系统截屏限制。翻掌朝向符号由同一只手正确示范建立，尚未真机验证。调试签名可能不同。

### A3 安装签名兼容构建
A3 用户反馈华为安装器显示无证书。原 CI 在默认 minSdk31 下显示 V2 验证通过、V1 false（不能据此证明 V1 不存在）。此构建明确启用 V1/V2 签名，额外以 min-sdk-version 23 验证两种签名并输出证书指纹；应用代码、版本及包名不变。仍使用 CI 调试证书，不保证与旧版本签名一致；不关闭系统安全检查。请核对 APK SHA256、优先使用文件管理器安装或 adb install -r。未验证具体设备安装结果。

## A4 两种新姿势（替代 A3 上/下挥）
上滑：指尖朝上、手掌侧对镜头，保持指向转至掌心正对镜头。侧掌起始用于区分原地手背→手心（点击）。下滑：直接握拳就绪，再张开手掌、掌心正对镜头；截图仍是张掌就绪→握拳，且需显式启用。两项独立校准终点朝向，旧上/下校准自动失效；覆盖安装且证书一致时其余五项保留。无需额外上下位移。其余手势、权限与签名方式不变。朝向由正确示范确定，尚未真机验证。

## A4R1 映射交换及智能提示
指尖朝上侧掌→掌心朝镜头改为下滑；握拳→张开掌心朝镜头改为上滑。内部 Action ID、识别逻辑及校准键不变，覆盖安装且证书一致时七项校准均保留。其他五种映射不变。外部悬浮提示在有效起始姿势/识别过程出现，最后有效活动约2秒后隐藏；执行反馈原有约2.2秒显示时间保留；未启用、窗口受限或相机画面过期时隐藏，应用内诊断和校准提示保留。悬浮提示开关和位置不变。不改变签名配置；CI 临时调试密钥可能导致无法覆盖安装。未真机验证。
